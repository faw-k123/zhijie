# P12.4.9 前端审批状态展示报告

## 1. 修改位置

- `frontend/src/types/research.ts`：`ResearchCodingIndicator` 新增可选审批字段；
- `frontend/src/components/research/ScoreIndicator.vue`：每个指标卡片增加审批状态、评分状态、审批人和日期。

## 2. 展示映射

| 数据值 | 展示 |
|---|---|
| `approved` | 已批准 |
| `approved_revoked` | 已批准撤回 |
| `not_applicable` | 不适用 |
| `pending` | 待审批 |
| 缺失/null | 未记录 |

评分状态：

| 数据值 | 展示 |
|---|---|
| `approved` | 评分已生效 |
| `revoked_approved` | 评分已撤回 |
| `null` | 未知 |
| 其他 | 原值 |
| 缺失 | 未记录 |

## 3. 关键行为

- 撤回指标分数显示“未知”，不显示 0；
- 有审批人/日期时显示；
- 旧版本没有审批字段时显示“未记录”，不报错；
- 不改变评分、证据、来源链接；
- 不改变案例筛选、详情、分页和统计。

## 4. 响应式

审批徽章使用 `flex-wrap`，在既有的指标卡网格内自动换行；  
移动端沿用原案例详情断点，不新增横向溢出。

```text

npm run build-only：passed
```

- 没有修改审批决定；
