# P15.6 研究结论边界

## 必须保留的十项限制

1. 严格个人样本只有 **2 例**，不能形成稳定的群体统计结论。
2. 扩展跨文化样本 36 例，内部包含机构、团队、合作和个人，不能当作同质总体。
3. 两组样本量高度不平衡：2 对 36。
4. 两组缺失率明显不同：严格组 14/20 有效，扩展组 63/360 有效，均值比较存在选择偏差。
5. CASE007 仍为 `pending_review`，不纳入两组正式比较。
6. 306 条 null 仍是未知值，不是 0 分。
7. `activity_status` 缺失，不能推断所有案例的活动完成状态。
8. 62 条来源关系不等于 62 个独立来源。
9. 描述性差异不代表因果关系或统计显著性。
10. 不能据此建立全球传统音乐传播效果排名。

## 其他边界

- 未做 t 检验、ANOVA、卡方或置信区间；
- 未把同一案例的多个指标当作独立样本；
- 未把节目单、公告或机构介绍当作传播结果；
- 未把评论来源国家当作受众偏好；
- 未将扩展组称为严格个人样本；
- 未因缺失而补 0 或重新归一化。

## 结论使用方式

P15 结果只能用于：

- 描述两个样本组的现有证据结构；
- 提出后续研究假设；
- 识别数据缺口；
- 设计 P16 的音乐/区域分析。

不能用于：

- 宣称某类主体传播效果更好；
- 宣称个人演奏优于机构传播；
- 宣称某个国家/乐器具有普遍接受度；
- 形成效果排名或政策结论。
