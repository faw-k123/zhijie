# v1.2 P6：案例证据增强报告

> 范围：CASE011–CASE020（第一批 10 个新增扩展案例）  
> 产出：100 条“案例 × 指标”证据映射；38 条草稿评分；62 条仍为 null。  
> 状态：draft_pending；没有写回 v1.2 原始 JSON。

## 1. 为什么选这 10 个

按现有证据基础排序，优先选择：

- 有机构/教育/合奏入口；
- 有具体活动页或节目单；
- 有乐器或年度活动信息；
- 不选只有模糊机构介绍、没有活动入口的候选。

## 2. 指标证据规则

| 指标 | 可接受证据 | 不接受 |
|---|---|---|
| 情感共鸣 | 受众原话、评论、演出后反馈 | 机构介绍、活动规模 |
| 音色辨识度 | 录音/录像、音色描述、专业评论 | 乐器名称本身 |
| 故事可解释性 | 曲目介绍、艺术家访谈、节目说明 | 仅机构名称 |
| 跨文化适配度 | 明确的跨文化合作/改编记录 | 仅“国际交流”口号 |
| 教育支持度 | 课程、教学、招新、工作坊 | 仅机构存在 |
| 文化桥梁作用 | 主办方/媒体明确的文化交流叙述 | 演出次数 |
| 受众参与度 | 互动记录、观众反馈、参与数据 | 新闻稿“观众喝彩” |
| 传播渠道适配 | 具体渠道/场地/活动记录 | 机构知名度 |
| 时代主题关联 | 明确的主题/纪念/交流框架 | 乐器古老程度 |
| 可持续性 | 多年活动、年度系列、持续课程 | 单次活动 |
