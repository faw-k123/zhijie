## 4. 活动状态限制

v1.6 仍不包含 `activity_status` 字段。

发布说明必须明确：

- 公告不等于演出完成；
- 节目单不等于现场；
- 不得从缺失来源推断活动状态；
- `announcement`、`program_listed`、`performed_confirmed`、`outcome_verified` 只能逐案依据来源判断；
- 本版本没有批量补写或推断 activity_status。
