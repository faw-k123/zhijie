> 只描述两组现有评分；不进行显著性检验，不建立群体排名。  
> strict 每项最多 2 个独立案例评分。

## 3. 扩展组

扩展组各项 n 在 1–10 之间；  
即使均值可算，也不能当作总体参数估计，因为：

- 缺失 297/360；
- 组内包含机构、团队、合作等异质主体；
- 同一案例贡献多项评分，不独立；
- 评分不是连续测量。

## 4. 0 与 null

```text
strict：0 个 0 分，6 个 null
extended：0 个 0 分，297 个 null
```

null 没有转为 0。
