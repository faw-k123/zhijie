# P7 区域传播方案页报告

> 项目：智解国音 · 中国传统音乐国际传播分析与智能决策系统
> 阶段：P7（区域传播方案生成）
> 日期：2026-10-30
> 状态：P7 完成，等待最终验收
> 范围：新增结构化方案接口；结构化页面现为 `/promo-plan`；`/promo-report` 已恢复为旧版宣传文案生成页

---

## 1. 本阶段完成内容

1. 新增 `/promo-plan` 为“区域传播方案”页面；`/promo-report` 保留旧版宣传文案生成页。
2. 保留 12 项输入，按音乐信息、目标市场、受众、传播目标、渠道与形式、活动条件分组。
3. 北京/上海作为“作品来源城市”音乐元数据子字段，不替代目标城市。
4. 新增 `POST /api/research/promo-plan/`，使用规则模板生成 9 个结构化模块。
5. 每个模块固定返回：
   - 已有证据
   - 策略建议
   - 待验证假设
   - 证据缺口
6. 页面按四种类型分色展示，不把建议或假设写成研究事实。
7. 没有评分、关联案例或区域策略时，明确显示证据缺口，不编造文化禁忌、受众偏好或效果提升百分比。
8. 原有 `POST /api/promo/report/` 保留，行为不变。

## 2. 输入设计

### 2.1 12 项必填输入

| # | 输入 | 说明 |
|---:|---|---|
| 1 | 目标音乐 | 曲名，支持与 P6 单曲上下文精确匹配 |
| 2 | 目标国家/地区 | 目标市场 |
| 3 | 目标城市 | 目标市场城市 |
| 4 | 目标受众 | 音乐学院学生、华裔社群、青年短视频用户等 |
| 5 | 年龄范围 | 18-24 / 25-34 / 35-49 / 50+ / 全年龄 |
| 6 | 传播目的 | 文化交流、非遗传播、青年交流等 |
| 7 | 主要传播平台 | 短视频、社交媒体、音乐学院/艺术节等 |
| 8 | 内容表现形式 | 短视频、纪录片、音乐会、工作坊等 |
| 9 | 是否允许跨文化改编 | 允许 / 不允许 / 尚未决定 |
| 10 | 预算范围 | 低 / 中等 / 高 / 未定 |
| 11 | 活动周期 | 1 / 3 / 6 / 12 个月 |
| 12 | 传播语言 | 中文、English、Deutsch、Français 等 |

### 2.2 来源城市元数据

- “作品来源城市”是音乐信息组内的**可选元数据子字段**，不是第 13 个独立输入类别。
- 可选：未提供 / 北京 / 上海 / 其他。
- 用途：触发输出 01 的城市叙事建议；不替代目标国家/城市分析。
- 没有来源城市时，输出明确写“暂不启用北京/上海城市叙事”。

---

## 3. 输出设计：9 个模块

每个模块固定包含四类内容：

```text
evidence      已有证据（只能来自研究数据）
suggestions   策略建议（带 basis）
hypotheses    待验证假设（带 validation）
gaps          证据缺口（带 action）
```

| # | 模块 | 当前主要输出 |
|---:|---|---|
| 01 | 音乐与文化定位 | 曲目定位建议；来源城市（上海）建议；缺评分证据 |
| 02 | 目标区域分析 | 本地顾问审阅建议；目标受众接受方式假设；缺区域文化/宗教来源 |
| 03 | 目标受众分析 | 受众/年龄设定建议；兴趣假设；缺受众调研 |
| 04 | 音乐适配分析 | 评估框架建议；适配度假设；缺单曲评分/案例/区域策略 |
| 05 | 跨文化表达策略 | 改编许可对应的建议；理解度测试假设；缺改编案例 |
| 06 | 传播主题设计 | 由传播目的推出主题建议；主题共鸣假设；缺案例主题证据 |
| 07 | 渠道与内容规划 | 平台/形式/语言建议；渠道效率假设；缺渠道数据 |
| 08 | 执行计划 | 周期分段与预算档位建议；不虚构金额；缺历史成本 |
| 09 | 效果评估 | KPI 与过程指标建议；试点前后对照假设；缺历史基线 |

## 4. 实际测试案例

### 4.1 输入

```json
{
  "title": "春江花月夜",
  "target_country": "德国",
  "target_city": "柏林",
  "target_audience": "音乐学院学生",
  "age_range": "25-34",
  "purpose": "文化交流",
  "platform": "音乐学院 / 艺术节",
  "content_format": "音乐会",
  "adaptation_allowed": "yes",
  "budget_range": "中等",
  "duration": "3个月",
  "language": "Deutsch",
  "origin_city": "上海"
}
```

### 4.2 实际生成结果

- `generation_mode`: `rule_template`
- `ai_generated`: `false`
- 模块数：9
- 已有证据：0
- 策略建议：16
- 待验证假设：9
- 证据缺口：9

证据摘要：

```text
音乐潜力：资料不足（0 / 8 项有评分）
精确关联案例：0
区域策略：0
来源：0
```

模块 01 中出现了“可将上海作为作品来源城市”的建议，但同时注明：

- 具体城市文化锚点、场景与来源仍需补充；
- 来源城市叙事是否能提升目标受众理解，尚待验证；
- 当前没有音乐潜力评分，不能给出有评分依据的定位强度判断。

### 4.3 真实性检查

当前结果没有：

- 具体宗教禁忌
- 具体国家受众偏好
- 具体区域适配结论
- 效果提升百分比
- 虚构预算金额或精确排期

例如，页面不会写“二胡非常适合德国市场”，而是写：

> 当前没有该曲的评分、精确关联案例或区域策略，无法判断音乐与目标区域/受众的适配性。

## 8. 已知限制

1. 当前 `music_scores.items=[]`，所以方案页面会显示“音乐潜力 资料不足（0/8）”。
2. 当前没有 `related_case_ids`，所以精确关联案例为 0。
3. 当前 `regional_strategies.rows=0`，所以区域策略为 0，文化/宗教注意事项只能显示为证据缺口。
4. “来源城市”是可选元数据，不替代目标国家/城市，也不能单独支撑城市文化判断。
5. 规则模板只生成执行建议和验证路径，不替代真实受众调查、文化顾问审核或效果评估。
6. 390 下页面主体可用；AppNav 仍有全站既有横向溢出。
