## 3. 能证明什么

- 活动确实在海外面向公众发生（C002–C005）；
- 有具体国家、城市、场地、日期；
- 有部分曲目/乐器（C001、C002、C003）；
- 有主办方/媒体来源。

## 4. 不能证明什么

- 当地受众偏好；
- 传播效果/上座率/转化；
- 中国团队演出等于外国个人演奏；
- 记者“enthusiastic responses/掌声”等于量化受众反馈；
- 一次活动等于长期影响。

## 5. 关键限制

### 新加坡

- 演出页与 MOU 同日；没有演出后记录；
- 不能写 `performed_confirmed`。

### 阿联酋

- 中国团队（泉州师院）；
- 观众引语为记者转述；
- 适合扩展跨文化案例，不是严格外国个人。

### 墨西哥

- 中国二胡演奏者 + 墨西哥音乐家；
- 演出后报道明确，但无独立评论；
- 适合跨文化合作案例。

### 阿根廷

- 图片报道缺具体曲目/乐器；
- 活动完成成立，细节不足。

### 韩国

- PR Newswire 稿；
- 宣传性“enthusiastic responses”不能当受众数据；
- 具体曲目/乐器不足。

## 6. 结论

5 条候选可进入下一轮核验，但不能直接写入正式案例。  
优先核验顺序：C002（阿联酋）、C003（墨西哥）、C001（新加坡）、C004（阿根廷）、C005（韩国）。
