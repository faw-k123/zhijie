## 1. 编码规则

- 每项 0–3 分；
- 无证据填 null，不填 0；
- 每个有效分数有 source_id 和证据说明；
- 同源 Xinhua 英文/阿拉伯语/西语稿只算一个来源依赖组；
- 观众引语不上升为整体受众偏好；
- 单次活动不写成长期传播效果。
