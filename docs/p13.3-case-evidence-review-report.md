## 2. 逐条判断

### P13-C001 科威特

- 新华社演出后图文报道；
- 现场照片证明活动发生；
- 但**未列具体乐器、曲目、演奏者名单**；
- 是中国音乐家团队，不是外国个人；
- 单来源，不能证明受众偏好；
- 结论：`needs_more_evidence`。

### P12-C001 新加坡

- NAFA/SCO 官方活动页；
- 有曲目与中阮协奏；
- 但只是 `program_listed`，没有演出后记录；
- 不能证明现场完成和受众反馈；
- 结论：`needs_more_evidence`。

### P12-C004 阿根廷

- 新华社图片报道确认科隆剧院演出；
- 但未列具体乐器、曲目、演奏者名单；
- 单来源；
- 结论：`needs_more_evidence`。

### P12-C005 韩国

- 来源是 PR Newswire 稿；
- 缺独立评论、具体曲目/乐器；
- “enthusiastic responses”属于宣传性概括；
- 结论：`needs_more_evidence`。

## 3. 关键边界

- 演出完成 ≠ 传播成功；
- 活动页 ≠ 演出完成；
- 宣传稿 ≠ 独立受众反馈；
- 中国团队 ≠ 外国个人；
- 单来源不能支撑“区域受众偏好”；
- 缺具体乐器/曲目时，不能进入正式案例。

## 4. 为什么 0 条 approved

正式案例至少需要可核验的：

```text
主体
国家/地点
活动日期
具体中国乐器
具体曲目/音乐内容
实际演出状态
来源
```

4 条候选都至少缺一项，因此不能进入 P13.4。
