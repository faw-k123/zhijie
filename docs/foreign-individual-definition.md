# “外国个人”身份判定标准（v1.2 研究设计）

> 版本：v1.2 第三阶段  
> 日期：2026-11-01  
> 适用范围：v1.2 候选审核、严格个人样本与扩展样本分类  
> 状态：研究设计文档；不创建正式案例、不修改 v1.1 / active_version

---

## 1. 严格个人样本的定义

严格个人样本中的“外国个人”，是指：

> 有可靠、可公开核验的证据支持其具有**非中国国籍**的具体个人。

“可靠证据”优先包括：

1. 政府、移民、使领馆或官方身份记录；
2. 本人官方网站/正式履历中的明确国籍表述；
3. 大学、音乐学院、乐团、主办方等机构官方页面中的明确国籍/国民身份表述；
4. 独立主流媒体的人物报道中明确写出国籍；
5. 其他可追溯、可复核的公开材料。

仅写“出生于某地”“成长于某地”“长期居住某地”“在海外演出”，不等于具有外国国籍。

---

## 2. 禁止推断

不得根据以下信息推断国籍：

- 姓名；
- 外貌；
- 族裔；
- 语言；
- 出生地；
- 成长经历；
- 长期居住地；
- 演出所在地；
- 所演奏的乐器；
- 所在乐团/学校的整体属性。

以上信息可以作为“身份线索”，但不能单独作为“非中国国籍”的证明。

---

## 3. 长期海外生活不等于外国国籍

中国国籍但长期在海外生活、教学、演出的个人：

- **可以**进入 `extended_cross_cultural` 扩展跨文化传播样本；
- **不得**进入 `strict_individual` 严格外国个人样本；
- 其海外活动、教学、合作可以单独作为扩展样本分析。

---

## 4. 身份不明

无法确认国籍时：

```text
identity_review_status = identity_pending
nationality_status = unverified
nationality_value = null
```

不得强行归类为“外国个人”，也不得因姓名或族裔直接排除。

---

## 5. 乐团、学校、社团和机构

- 乐团、学校、社团、机构不能直接认定为“外国个人”；
- 机构整体国籍/所在地不等于成员个人国籍；
- 乐团成员只有同时具备：
  1. 个人身份；
  2. 个人国籍；
  3. 具体中国乐器；
  4. 实际演奏事实；
  5. 可核验来源；
  
  才能作为个人候选单独审核；
- 团体案例归入扩展样本的“乐团/教育/社区传播”类别，不进入严格个人样本。

---

## 6. 三个维度不能互相替代

| 维度 | 回答的问题 | 不能替代 |
|---|---|---|
| 国籍身份 | 这个人是否具有非中国国籍？ | 不能由演出、乐器、居住地替代 |
| 演出事实 | 是否实际演奏了具体中国乐器？ | 不能由身份或节目单替代 |
| 传播效果 | 是否产生受众反馈/持续影响？ | 不能由演出记录替代 |

---

## 7. 字段规范

| 字段 | 取值 | 说明 |
|---|---|---|
| `nationality_status` | `verified` / `partial` / `unverified` / `not_applicable` | 只评价国籍证据 |
| `nationality_value` | 国家名 / `null` | 没有可靠来源时为空 |
| `nationality_source_ids` | string[] | 支持国籍判断的来源 |
| `identity_review_status` | `nationality_verified` / `identity_pending` / `group_not_individual` | 审核状态 |
| `strict_individual_eligibility` | `eligible_for_strict_review` / `ineligible_identity_pending` / `ineligible_not_individual` | 是否可进入严格复核 |
| `extended_sample_eligibility` | `eligible` / `ineligible` | 是否可进入扩展样本 |
| `eligibility_reason` | string | 必须写明依据与缺口 |

`strict_individual_eligibility=eligible_for_strict_review` **不等于正式批准**；它只表示可以进入下一轮严格复核。

---

## 8. 结论

本标准的直接后果：

- CAND024 可进入严格个人样本复核，但不是正式纳入；
- CAND026、CAND028、CAND033 国籍未确认，保留扩展样本；
- CAND036 为乐团/教育案例，归入扩展样本；
- 任何候选都不得因姓名、族裔或海外居住地被自动批准。
