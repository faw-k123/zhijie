- CASE008 的 `work` 字段明确列出这些曲目；

- 没有映射库中不存在的《长门怨》《忆故人》《越人歌》。

## 3. 关键区分

```text
mapping_status = verified
```

表示：案例曲目与音乐库曲目是同一首、版本选择正确。

```text
performance_status = program_listed
```

表示：曲目出现在活动/节目记录中，**没有演出后录像、评论或主办方完成记录**。

因此不能写成 `performed_confirmed`，也不能把曲目映射当成演出效果。
