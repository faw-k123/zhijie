# P14.6 描述性关联分析

> 本分析只比较分组后的有效评分，不做因果推断，不建立综合排名。  
> 所有分组同时报告 n 和 null；小样本组只作描述。

## 1. 分析维度

| 维度 | 分组数 | 说明 |
|---|---:|---|
| 国家 | 12 | 每案只归一个国家 |
| 乐器 | 9 | 多乐器案例可重复归组 |
| 案例类型 | 4 | 机构教育/个人跨文化/机构合奏/跨文化合奏 |
| 样本类型 | 3 | strict/extended/pending |
| 证据等级 | 1 | 全部 B，无法比较等级差异 |

关联统计表共 290 行：`research/analysis/p14/association_statistics.csv`。

## 2. 案例类型的描述性差异

| 指标 | 个人跨文化（n） | 跨文化合奏（n） |
|---|---|---|
| 故事可解释性 | 2.33（6） | 1.67（6） |
| 跨文化改编程度 | 2.17（6） | 2.33（6） |
| 外国演奏者桥梁作用 | 2.17（6） | 1.75（4） |
| 传播渠道适配度 | 2.50（6） | 1.50（4） |
| 传播持续性 | 3.00（6） | 2.00（3） |

只能说明这两组在现有有效评分上的描述差异；n 很小，不能当作稳定组间差异或因果结论。

## 3. 样本类型

扩展组：

```text
故事 1.80（n=10）
跨文化 2.30（n=10）
教育 2.40（n=5）
桥梁 2.13（n=8）
渠道 1.88（n=8）
时代 2.20（n=10）
持续 2.43（n=7）
```

严格组只有 2 例，逐项 n≤2，不计算均值；pending 组同样不计算。

## 4. 国家/乐器

- 国家组中许多国家只有 1–2 个案例；
- 乐器组多乐器重复归组；
- 不对国家/乐器均值排名；
- 德国 2 例有效评分为 0，不能解释为“德国传播效果差”，只能说明该组缺评分。

## 5. 相关分析

未计算 Pearson/Spearman 相关系数，原因：

- 多数分组有效 n<5；
- 指标缺失严重；
- 同一案例贡献多个指标，不独立；
- 评分是序数，不是连续测量；
- 样本类型混合。

## 6. 解释限制

```text
相关不等于因果
均值不等于传播成功
n 小不等于效应大
null 不等于 0
```
