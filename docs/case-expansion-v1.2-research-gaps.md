# 第二批候选研究缺口（v1.2 第一阶段）

## 1. 严格个人样本缺口

本批 35 条候选中，没有一条能直接进入 `strict_individual`。主要缺口：

- 缺少非华裔个人演奏者的主办方节目单/演出评论；
- 机构页无法证明成员国籍；
- 中国境内活动被误当海外活动；
- 个人官网只能证明自述，不能独立证明演出。

## 2. 受众证据缺口

- 情感共通性：本批几乎没有受众评论/访谈原文；
- 音色辨识度：几乎没有受众对音色的描述；
- 受众参与度：几乎没有学习、翻奏、二创记录。

## 3. 地区/乐器缺口

- 现有正式库以美、英、法、日、加、澳为主；德国、荷兰、新西兰多为机构/活动线索；
- 古筝/二胡/古琴较多，琵琶、中阮、笛子、笙、扬琴、唢呐、管子证据薄。

## 4. 下一步检索优先级

1. 非华裔个人演奏者的海外主办方节目单；
2. 音乐学院/大学的世界音乐合奏成员名单与音乐会节目单；
3. 独立媒体演出评论中的受众反应；
4. 有受众评论/二创/教学记录的平台页面；
5. 不把机构页、乐团页、个人自述直接升格为严格案例。
