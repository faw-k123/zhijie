## 2. 来源质量

本阶段未重新打开全部来源页面：

```text
外部页面重开：0
URL 状态：NOT_REOPENED
发布主体：已有元数据
```

因此：

- 不能确认所有 URL 仍有效；
- 不能确认所有页面仍可访问；
- 不能把来源存在当作内容已复核；
- 来源质量问题需要人工补查。

## 3. 同源风险

已识别同机构风险：

- Xinhua 多语种/多页面；
- 同一机构多个页面引用同一材料；
- 同一活动多平台转载。

`source_quality_audit.csv` 提供 `cluster_id` 和 `quality_flags`，但没有把网页数量当作独立来源数量。

## 4. 不能声称

- 62 条来源关系 = 62 个独立来源；
- 来源数多 = 证据强；
- 机构官网存在 = 活动发生；
- 媒体转载 = 独立事实。
