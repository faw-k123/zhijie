## 2. 前七项受众量表（1—5）

统一指导语：

> 1 = 完全不同意/完全不能；5 = 非常同意/非常清楚。  
> 请按你实际感受作答，没有标准答案。

### Q1 情绪共鸣

这段音乐在多大程度上触动了你的情绪？

- 1：完全没有情绪反应
- 2：轻微
- 3：中等
- 4：明显
- 5：强烈触动，愿意继续听或分享

字段：`emotional_resonance`

### Q2 音色辨识

你能多清楚地辨认出这种乐器/声音的独特音色？

- 1：听不出独特音色
- 2：有一点
- 3：能大致辨认
- 4：清楚辨认
- 5：音色非常独特且能描述

字段：`timbre_identity`

### Q3 旋律可进入性

旋律对你来说有多容易跟随和记住？

- 1：难以跟随或记住
- 2：较难
- 3：一般
- 4：较容易
- 5：很容易跟随，能哼出片段

字段：`melody_accessibility`

### Q4 文化故事性

音乐和导赏让你理解了多少背后的文化故事？

- 1：完全没有理解
- 2：很少
- 3：部分理解
- 4：较清楚
- 5：能清楚复述故事和背景

字段：`cultural_story`

### Q5 跨文化改编空间

你觉得这种音乐与当地音乐元素结合的空间有多大？

- 1：完全不适合结合
- 2：空间很小
- 3：可以尝试
- 4：结合空间较大
- 5：结合自然，愿意听更多

字段：`adaptation_space`

### Q6 视觉表现力

提供的视觉呈现与音乐有多匹配、多有表现力？

- 1：视觉与音乐不匹配
- 2：较弱
- 3：一般
- 4：较好
- 5：视觉显著增强音乐表现

字段：`visual_expressiveness`  
**无视觉材料规则：记 missing，不补 3 分，不进入正式评分。**

### Q7 时代主题相关性

音乐与导赏提出的当代主题有多相关？

- 1：看不出关联
- 2：关联较弱
- 3：有一定关联
- 4：关联清楚
- 5：关联清晰且与我的当代经验相连

字段：`era_theme_relevance`

## 3. 既有传播证据（研究人员填写，不由受众回答）

- 0—100 分；
- 必须附来源、规则版本、录入人、审批人；
- 未审批不得进入正式评分；
- 不能把播放量、点赞数直接等同于文化接受。

字段：`existing_evidence`

## 4. 辅助指标（不进入八项正式分）

| 字段 | 题目/取值 |
|---|---|
| `save_share_intent` | 我愿意收藏或分享这段音乐：1—5 |
| `learning_intent` | 我想进一步了解或学习：1—5 |
| `open_response` | 你喜欢/不理解/联想到什么？ |
| `cultural_risk_flag` | 是否出现宗教、刻板印象、误读或不适？ |

## 5. 缺失、反向题和异常值

- 缺失：不补 3 分，不补 0 分；记 missing。
- 反向题：本版本无反向题；新增时必须先反向计分，再转 0—100。
- 视觉材料缺失：`visual_expressiveness` 记 missing，不进入正式评分。
- 完成率 < 70%：排除。
- 量表越界：隔离并输出错误报告。
- 未同意、重复 participant、试运行数据：排除。
