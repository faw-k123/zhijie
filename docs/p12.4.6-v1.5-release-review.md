## 3. 阻断项 1：评分审批状态未同步

v1.5-draft 中新增评分：

```text
CASE037:
  story_explainability = 1, score_status=revised_draft_pending_approval
  cross_cultural_adaptation = 2, score_status=revised_draft_pending_approval
  era_theme_relevance = 2, score_status=revised_draft_pending_approval
  channel_fit = null, score_status=revoked_pending_approval

CASE038:
  story_explainability = 1, score_status=revised_draft_pending_approval
  cross_cultural_adaptation = 2, score_status=revised_draft_pending_approval
  era_theme_relevance = 1, score_status=revised_draft_pending_approval
  channel_fit = null, score_status=revoked_pending_approval
```

但负责人已在 P12.4.4 批准这些评分。  
因此发布前必须把 `approval_status`/`score_status` 从 pending 更新为 approved/revoked，否则正式版本仍显示“未审批”。

## 4. 阻断项 2：版本标识不可直接激活

当前：

```text
目录：research/data/v1.5-draft
data_version：v1.5-draft
主 manifest：未加入
```

项目校验器要求版本目录/`data_version` 与 active_version 一致；`v1.5-draft` 不能直接作为正式 `v1.5` 加载。

发布前需要：

- 建立正式 `v1.5` 目录或明确的版本归一流程；
- `cases.json` / `success_factors.json` / `music_scores.json` / `regional_strategies.json` 的 `data_version` 改为 `v1.5`；
- 在主 manifest 增加 v1.5 条目；
- 重新计算文件哈希；
- 重新运行校验。

这些操作本轮没有执行。
