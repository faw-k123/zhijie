## 3. 解释限制

- 情感共通性、音色辨识度只有 n=3；
- 受众参与度 n=4；
- 这些均值不能当作稳定总体估计；
- 94 条有效评分不是 94 个独立案例；
- 400 条记录不是 400 个独立观察；
- 各指标缺失率高，不能做完整排名或综合分。
