# 六国首轮试验招募与执行手册（候选稿）

> 状态：待研究负责人审批、待本地翻译审校、待伦理/机构许可  
> 不包含任何真实受众数据

## 1. 上线前必须完成

```text
[ ] 研究负责人批准协议版本
[ ] 六国本地语言翻译 + 独立审校
[ ] 伦理/机构审查（如适用）
[ ] 音频、视频、字幕在目标设备可播放
[ ] 试运行 pilot_rehearsal 完成并复盘
[ ] 门槛配置审批
[ ] operator/approver 令牌发放
```

任一项未完成，不得正式招募。

## 2. 角色

```text
研究负责人：批准协议、门槛、证据分、评分、发布
operator：招募/导入/录入证据/生成草稿
approver：复核与审批，不参与同一批次的录入
本地顾问：翻译审校、宗教文化风险复核
```

## 3. 参与者流程

1. 阅读本地语言研究说明；
2. 完成同意；未同意不得进入正式采集；
3. 系统生成去标识化 participant_code；
4. 按国家、曲目、版本分配；保存分配种子和日志；
5. 播放音频/视频；记录开始、完成、提交时间；
6. 填写七项量表、辅助指标、开放回答；
7. 提交；系统记录观看率；
8. 退出者数据标记 withdrawn，不进入分析。

## 4. 目标

```text
每国×曲目×版本：20
每国×曲目：40
每国总有效样本：120
每国覆盖单元：12
```

## 5. 试运行

- 每国先做小规模 `pilot_rehearsal`；
- 检查播放、题目理解、翻译、完成时间、随机分配、风险提示、CSV 导入；
- 试运行数据不进入正式聚合；
- 发现问题创建新协议/问卷版本，不覆盖旧版本。

## 6. 数据操作

```text
CSV 导入 → raw_deidentified / clean / rejected / errors / conflicts
→ 批次审批 → 聚合 → 证据分审批 → 评分草稿
→ 评分审批 → 发布 → 排名
```

禁止：

- 用 0 补缺失；
- 把播放量当接受；
- 从国籍推断宗教/偏好；
- 用试运行数据冒充正式数据；
- 同一 response_id 跨批次重复。

## 7. 停止规则

- 翻译未审校：停止；
- 同意流程异常：停止；
- 音频无法播放：停止；
- 跨批次重复无法隔离：停止；
- 文化风险事件：暂停并复核；
- 门槛未审批：不得发布正式评分。
