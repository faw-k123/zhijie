## 3. 质量问题

### comment.id 重复

```text
重复 id 分组：14,628
```

本阶段不按 `comment.id` 去重，所有统计按 `song_id` 聚合。

### 情感缺失

```text
58,789 / 192,882 = 30.48%
```

缺失不填 0；sentiment 均值只对有效值计算。

### 点赞异常

```text
likes = 2,147,483,647：2 条
```

异常值不进入正常点赞总和。

### 无 user_id

评论不能直接做用户级去重、聚类或跨歌曲偏好分析。

## 4. emotion_index

- 81,388 条时间序列；
- `emotion_index` 仅作描述性指标；
- 无公式依据时不能解释为具体情绪强度；
- 不能等同于传播效果。

## 5. 评论量/情感不能证明

- 评论多不等于传播成功；
- 情感正不等于受众接受；
- 来源国家不等于目标市场；
- 不同歌曲评论量不能直接排名传播潜力。
