# P12.4.9 API 审批状态支持报告

## 1. 修改内容

`get_case_detail()` 的每个 indicator 对象新增：

```text
approval_status
score_status
approver
approval_date
```

原有字段全部保留：

```text
indicator_id
label
order
score
evidence
source_ids
missing_reason
```

## 2. 兼容规则

- 旧版本没有审批字段：返回 `null`，前端显示“未记录”；
- 有审批字段：返回文件中的正式值，不重写；
- 撤回指标：`score=null`，不进入有效评分统计；
- `null` 不转 0；
- 不改变评分、证据、来源关联。
