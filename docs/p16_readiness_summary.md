# P16.6 302首歌曲分析准备度分层

## 1. 分类结果

| 类别 | 定义 | 歌曲数 |
|---|---|---:|
| 第一类 | 八因素完整，可算综合分 | 0 |
| 第二类 | 有部分指标，但无完整分 | 0 |
| 第三类 | 有明确歌曲—案例关联，但潜力数据不完整 | 5 |
| 第四类 | 缺乏明确歌曲级证据或关键数据质量不足 | 297 |

## 2. 第三类：5 首 CASE008 曲目

```text
23 平沙落雁
158 梅花三弄
26 流水
28 酒狂
29 阳关三叠
```

它们有：

- CASE008 具体曲目节目单关联；
- 案例级故事/跨文化/时代评分；
- 节目单来源 C008-S001。

它们没有：

- 音色、旋律、视觉特征；
- 受众反馈；
- 实际演出确认；
- 完整八因素。

因此归入第三类，不进入第一类。

## 3. 第二类为什么是 0

评论情感是辅助描述，不是已验证的“情感普适性”因素分。  
没有案例级证据的歌曲，不能仅凭评论量或情感均值进入第二类。

## 4. 第四类：297 首

- 无明确歌曲—案例关联；
- 无歌曲级八因素依据；
- 不能做综合潜力排名。

这是数据现状，不是歌曲价值判断。
