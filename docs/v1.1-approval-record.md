## 3. 正式严格样本

只有 `approved` 计入正式严格样本：

```text
CASE005 Clare Cooper
CASE006 Jarrelle Barton
```

数量：

```text
strict_candidate_count = 3
owner_approved_count = 2
strict_approved_case_count = 2
pending_owner_review_count = 0
rejected_count = 0
needs_more_evidence_count = 1
```

有效评分：

```text
CASE005 = 6 条
CASE006 = 8 条
正式严格样本有效评分记录 = 14 条
```

> 正式严格样本是 2 个独立案例，不是 14 个样本。14 条是评分记录数，不能当作案例数。
