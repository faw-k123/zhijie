> 来源数量不等于独立来源数量；同一机构多语种/转载按同一来源组处理。

| 每案来源数 | 案例数 |


例如 CASE039/CASE040 各有两条来源，但分别是同一 Xinhua 的英文/阿拉伯语或英文/西语版本，不能算两个独立来源。

## 3. 证据等级

```text
B 级：40/40
A/C/D：0
```

全部为 B 级说明当前证据等级没有区分度；B 级也不等于传播效果良好。

## 4. 可追溯性

- 有效评分均保留 source_id；
- 62 条来源关系均可关联；
- 但来源数量少、独立性弱；
- 不能从来源缺失推断活动未发生；
- 不能从活动公告推断演出完成；
- 不能从活动举办推断传播成功。

## 5. activity_status

40/40 仍为 `NOT_RECORDED`。  
公告、节目单、演出完成、结果验证无法从字段自动区分。
