# research/data

本目录存放程序只读的正式研究数据。后端通过主 `manifest.json` 的 `active_version` 选择已审核版本，并校验四个核心数据文件的大小和 SHA256。

## 当前正式版本

```text
active_version = v1.8
status = reviewed
案例总数 = 45
正式严格样本 = 10
来源记录 = 113
指标记录 = 450（有效154，未知296）
候选音乐 = 20（已选曲，八项评分待六国实测）
区域策略 = 6国
```

v1.8 在 v1.7 基础上将案例库扩充至80例，优先补充原低样本国家；80例全部进入案例展示、国家覆盖、因素统计与歌曲对应分析。原有20首候选音乐和区域适配方案继续沿用，并按v1.8案例数据动态关联。

## 规则

- 已发布版本只读；后续修订新建版本，不覆盖 v1.8；
- 非空指标分数必须带证据与案例来源；未知保持 `null`，不写成0；
- 严格案例成立不等于传播成功，受众结果单独编码；
- 曲目已入选不等于已完成潜力评分，20首的八项分数在六国实测前保持 `null`；
- 六国矩阵是获批的试验设计，不代表国家或宗教群体的总体偏好；
- 字段、类型、枚举与校验规则见 [data-contract-v1.md](../../docs/data-contract-v1.md)。

## 主要文件

- `v1.8/cases.json`：80个已审批案例，其中10个严格外国个人样本、70个扩展传播案例；
- `v1.8/success_factors.json`：80例的10项因素编码与证据缺口；
- `v1.8/music_scores.json`：20首入选曲目及逐曲独立分析；
- `v1.8/regional_strategies.json`：区域适配策略；
- `v1.8/sources.json`：148条案例与策略来源；
- `v1.8/manifest.json`：版本内部统计与文件哈希。
