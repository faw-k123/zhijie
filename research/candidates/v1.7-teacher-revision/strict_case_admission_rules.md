# 严格外国个人演奏案例准入规则 v1.7

## 1. 研究对象

严格案例回答的是：

> 是否存在一名可核实的非中国国籍个人，实际公开演奏中国传统乐器、传统曲目，或以中国传统音乐为核心的跨文化改编，并形成可追溯的传播事件？

它不直接回答“是否成功”“外国受众是否接受”。传播结果必须另行采集受众证据。

## 2. 六项硬门槛

| 门槛 | 必须满足的条件 | 可接受证据 | 不可替代的内容 |
|---|---|---|---|
| G1 个人身份 | 具名自然人，不是学校、乐团或机构 | 本人正式履历、政府/高校/主办方、独立媒体 | 团体所在地不能代替个人身份 |
| G2 非中国国籍 | 来源直接写明外国国籍或国民身份 | 政府记录、机构正式履历、主流媒体明确表述 | 姓名、外貌、出生地、居住地不能单独推断国籍 |
| G3 中国音乐对象 | 明确的中国传统乐器、传统曲目，或以其为核心的跨文化改编 | 节目单、演出页、艺术家履历、演出录像说明 | 仅“喜欢中国文化”不成立 |
| G4 实际演奏 | 有演出后报道、录像、档案或正式履历确认实际演奏 | `performed_confirmed` 优先；持续演奏履历可接受 | 预告、节目单不能自动当作演出完成 |
| G5 传播场景 | 中国境外现场，或面向跨国受众的公开数字传播 | 海外主办方、场馆、平台、巡演/教学记录 | 仅在中国境内演出须另有国际传播证据 |
| G6 可追溯来源 | 至少两条来源，且能共同覆盖身份、乐器和演奏事实 | 至少一条机构/政府/主流媒体/本人正式履历 | 两条同稿转载不算独立双来源 |

六项全部满足时：

```text
strict_evidence_status = eligible_for_strict_review
```

负责人审核后才可变为：

```text
owner_approval_status = approved
analysis_sample = strict_individual
```

## 3. 传播成功不是准入门槛

以下字段不影响案例事实成立，但决定该案例能否进入“为什么接受”的分析：

| 字段 | 取值 |
|---|---|
| `audience_feedback_status` | `not_collected` / `partial_existing_not_coded` / `coded` |
| `outcome_evidence_status` | `none` / `reach_only` / `engagement` / `acceptance` / `conversion` / `institutionalized` |
| `feedback_language` | 受众反馈原文语言 |
| `feedback_country_basis` | 国家判断依据；无法判断时为空 |
| `feedback_sample_size` | 实际纳入编码的反馈条数 |

没有受众反馈时只能写“演奏/传播案例成立”，不得写“传播成功”。

## 4. 音乐对象分层

| 层级 | 含义 | 示例用途 |
|---|---|---|
| `traditional_repertoire` | 明确演奏传统曲目 | 用于研究传统曲目直接传播 |
| `traditional_instrument_contemporary_work` | 中国传统乐器演奏新创作 | 用于研究乐器音色与当代转译 |
| `cross_cultural_adaptation` | 中国乐器/曲目与当地风格融合 | 用于研究熟悉性桥梁与改编机制 |

分析时必须分层，不把三类混成同一种“传统音乐”。

## 5. 来源判定

- `high`：政府、高校、场馆、专业协会、正式艺术家/经纪履历、主流媒体原文；
- `medium`：行业媒体、专业艺术组织、可定位的演出报道；
- `low`：聚合页、无原始链接转载、无法确认发布者的社交内容；
- 同一发布机构、同一稿件的多网址合并为一个来源簇；
- 每个事实都要指向具体 `source_id`，不能用来源权威性替代来源正文。

## 6. 审核决策

| 结论 | 条件 |
|---|---|
| `approved_existing` | 已在正式版本中批准，且本轮未发现冲突 |
| `eligible_for_strict_review` | G1—G6 全部满足，等待负责人审批 |
| `needs_more_evidence` | 至少一项硬门槛未满足 |
| `rejected` | 身份、乐器或演奏事实与目标不符 |

## 7. 禁止事项

- 不按姓名或族裔推断国籍；
- 不把机构案例拆成个人案例，除非个人证据链完整；
- 不把活动预告当作实际演出；
- 不把播放量等同于文化接受；
- 不把主办方宣传语当受众反馈；
- 不因需要凑够数量而降低门槛。
